## 1. 目标

做一套给老板一个人看的电商财务系统：把淘宝 / 小红书、物流、ERP 库存、采购、工资、费用、发票的原始数据接进来，自动算出每家店、每个商品的真实利润，以及钱压在哪；每个汇总数都能下钻到明细，口径可核对。本期不接平台 API、不做多人权限和报税。

## 4. 实施结果

### 4.1 核算引擎（`src/engine.js`）

- 订单：GMV、退款（按退款月归集）、跨月退款冲减次月。
- 商品成本：移动加权平均，采购入库、销售出库、退货入库逐笔结转。
- 物流：首重 + 续重 + 区域加价 + 退回运费，按店铺 / 承运商 / 省份归集。
- 平台费用：佣金、软件服务费、支付手续费、运费险；有账单取实际值，无账单按费率估算。
- 推广：平台代扣 + 费用表推广，公共部分按收入占比分摊。
- 工资：底薪 + 补贴 + 阶梯提成（贡献毛利 / 净销售额可切换），退货冲减、跨月扣回；无店铺员工薪酬按收入占比分摊。
- 现金流：累计已回款、待结算、账期占款；打款与账单差异清单。
- 发票：进项 / 销项台账、关联单据匹配、金额差异、缺失发票。
- 勾稽：利润恒等式、店铺合计、库存滚动、成本勾稽、账单差异说明、打款核对、工资合计、负库存，共 8 项。

### 4.2 演示数据（`src/data.js`）

虚构美妆品牌「麓野 LUYE」，2026-08 ~ 2026-10，3 个店铺（天猫、淘宝奥莱、小红书），36 个 SKU，15,190 笔订单、24,034 条明细、15,190 张面单、9 张平台账单、60 张发票。数据自洽：公司净利 31.9 万（12.4%），8 项勾稽全部通过；账单保留 4 处**有说明**的差异（跨月结算、类目返佣、分位取整）和 1 笔 0.5 元打款差异，用于演示对账能力。

### 4.3 界面（`src/`）

11 个页面：经营总览、店铺利润、商品利润、平台结算、物流成本、采购与库存、工资与提成、费用与发票、数据导入、设置、口径与说明。

- 首页 5 组 KPI（净利润/净利率、店铺利润排名、现金流、成本结构、库存与滞销），首屏可见。
- 折线图、环形图、瀑布图、迷你趋势、进度条全部为自研 SVG，无外部依赖。
- 汇总行可下钻到店铺 / 商品 / 账单 / 员工 / 发票，店铺与商品弹窗含「最近订单明细」。
- 任意报表可导出 CSV（BOM、中文表头），可打印为 PDF；打印时隐藏导航，宽表压缩到纸张宽度不裁列。
- 设置可改店铺费率、提成阶梯、提成基数、滞销天数，保存后立即重算并持久化到浏览器。

### 4.4 数据导入（`src/importer.js`、`src/templates.js`、`src/xlsx.js`）

- 11 类模板：订单明细、物流面单、平台账单、平台打款、采购单、员工工资规则、费用、发票、商品主数据、店铺主数据、期初库存。
- 支持 CSV 与 .xlsx；中文表头别名映射；日期 / 金额 / 百分比清洗；店铺、商品、订单外键校验；主键重复与明细金额不平提醒。
- 错误行不写入；校验通过后可选追加或替换整表；导入后自动重算。
- 零依赖 xlsx 解析（zip + DecompressionStream + 共享字符串 / 日期格式），不联网。

## 7. 已知风险与假设

1. 演示品牌、店铺、供应商、员工、商品均为虚构，不含任何真实商家数据。
2. 演示平台费率为示例值（佣金 5%、软件服务费 2%、支付手续费 0.6%），可在设置按平台协议调整；公开口径参考见上。
3. 导入数据仅当前会话有效，刷新回演示数据；长期保存需导出 JSON 快照（使用说明已写明）。
4. 单文件依赖现代浏览器（Chrome 103+ / Safari 16.4+ / Firefox 113+），xlsx 解析需要 `DecompressionStream`；旧版浏览器请用 CSV。
5. Excel 单文件最多读取 20,000 行，超出截断并提示。
6. 打印字号 8px（约 6pt）偏小，QA 建议正式汇报可回调 9px 或 12/13 列改用 A4 横向（非阻断）。
7. 本期不含：多人账号权限、服务器部署、平台 API 直连、自动报税、发票税额抵扣计算、FIFO 等其它成本法。
