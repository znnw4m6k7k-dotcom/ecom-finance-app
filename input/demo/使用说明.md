# 电商财务集成管理系统 · 使用说明

一套给老板一个人看的电商财务系统：把淘宝 / 小红书、物流、ERP 库存、采购、工资、费用、发票的原始数据接进来，自动算出每家店、每个商品到底赚不赚钱，钱又压在哪。

**交付形态**：单文件 HTML，双击用浏览器打开即可，不需要安装服务器、不需要联网、不需要登录。

---

## 1. 怎么打开

1. 双击 `电商财务集成管理系统.html`（推荐 Chrome / Edge / Safari 较新版本）。
2. 首次打开会自动生成一套**虚构美妆品牌「麓野 LUYE」**的演示数据：2026 年 8–10 月、3 个店铺（天猫旗舰店、淘宝奥莱店、小红书品牌店）、36 个 SKU、约 1.5 万笔订单。
3. 页面顶部可切换账期（全部 / 8 月 / 9 月 / 10 月）和店铺；所有报表、图表、下钻会跟着变。

> 演示数据不代表任何真实商家。想换成自己的数据，见第 5 节。

## 2. 一页纸看懂：经营总览

首页固定展示 5 组老板最关心的指标：

| 指标 | 看什么 |
|---|---|
| 净利润 / 净利率 | 扣除商品成本、物流、平台费、推广、人工、其他费用后的真实利润 |
| 店铺利润排名 | 哪个店在赚钱、贡献占比多少、谁在拖后腿 |
| 现金流 | 平台已回款 / 待结算 / 账期占款——利润不等于现金 |
| 成本结构 | 商品、物流、平台费、推广、人工、其他各占营业收入多少 |
| 库存与滞销 | 库存金额、周转天数、滞销占用资金 |

下面还有收入与净利润趋势、成本结构环图、利润桥（收入如何变成净利润）、8 项勾稽校验和需要老板关注的异常。

**每个汇总数都能下钻**：点击店铺 / 商品 / 账单 / 员工 / 发票行，会打开明细；店铺和商品的明细里能看到最近 10 笔订单。

## 4. 核算口径（摘要）

完整版见系统内「口径与说明」页。

- **收入**：营业收入 =（GMV − 退款）+ 平台补贴；退款按退款发生月份归集，跨月退款冲减次月。
- **商品成本**：移动加权平均。采购入库后重算均价，销售按发货日当时均价结转，退货按退货日当时均价入库。
- **物流**：首重费 + 续重费 + 区域加价 + 退回运费，按面单实际金额归集。
- **平台费用**：佣金、软件服务费、支付手续费、运费险；有平台账单时取账单实际值，没有账单时按设置费率估算。演示默认：佣金 5%、软件服务费 2%、支付手续费 0.6%；公开参考口径为类目佣金 2%–5% + 基础软件服务费 0.6%（不封顶）、支付手续费 0.6% 仅贷记渠道，可在设置中按平台协议修改。
- **推广**：平台账单代扣推广费 + 费用表推广费；公共推广按店铺收入占比分摊。
- **人工**：底薪 + 补贴 + 提成；提成 = 店铺贡献毛利（或净销售额，可切换）按阶梯累进；无店铺员工薪酬按收入占比分摊到店。
- **公共费用**：按店铺营业收入占比分摊，分摊后各店净利之和 = 公司净利。
- **现金流**：时点口径，始终显示截至数据截止日（2026-10-31）的累计已回款、未结算账单金额与账期占款，不随账期切换；选店铺时显示该店口径。
- **发票**：关联单据存在且金额一致 = 已匹配；金额不符 = 差异；找不到单据 = 未匹配；采购/费用应有票未登记 = 缺失。

首页的 8 项勾稽会检查：利润恒等式、店铺合计、库存滚动、成本勾稽、账单差异说明、打款核对、工资合计、负库存。

## 5. 接入真实数据

支持 **CSV** 和 **.xlsx**（不支持旧版 .xls；请另存为 .xlsx 或 CSV）。

1. 进入「数据导入」，找到对应的表，点「下载模板」。模板是中文表头，带一行示例。
2. 把淘宝 / 小红书后台、快递 / 仓配、ERP、采购、工资表、发票系统导出的字段，按模板整理（列顺序不限，表头可用常见别名，系统会自动映射）。
3. 点「选择文件」，系统先做逐行校验：
   - 缺必填列、日期无效、数字格式错、店铺 / 商品 / 订单不存在、主键重复，都会列出行号和原因；
   - **有错误的行不会写入**，当前数据也不会被改动；
   - 校验通过后点「确认导入并重算」，可选择「追加 / 覆盖同号记录」或「替换整表」。
4. 导入后所有报表自动重算；导入的数据只在**当前这次会话**有效，刷新页面会回到内置演示数据。

**需要长期保存**：在「数据导入」页点「导出当前数据快照」（JSON），下次可据此恢复；系统不把明细写进浏览器本地存储，避免大文件把浏览器存储撑爆。

**常见导入顺序**：店铺主数据 / 商品主数据 → 订单明细 → 物流面单 / 平台账单 / 平台打款 → 采购单 / 期初库存 → 费用 / 发票 / 员工工资规则。

**文件上限**：单个 Excel 最多读取 20,000 行（超出会截断并提示）；超大文件请按月拆分。

## 6. 导出与打印

- 任意页面右上角「导出 CSV」：导出当前页面、当前筛选条件下的报表，Excel 可直接打开（带 UTF-8 BOM，中文不乱码）。
- 「打印」：浏览器打印对话框里选「另存为 PDF」，A4 纵向即可。打印样式会隐藏侧栏、顶栏和按钮，把宽表压缩到纸张宽度（不会丢列），并保留标题与口径说明。

## 7. 设置

- **店铺费率**：佣金率、软件服务费率、支付手续费率、运费险率、账期。有平台账单时损益取账单实际值，费率主要用于估算与对账基准。
- **提成阶梯**：可增删档位，左闭右开；提成基数可切换「贡献毛利 / 净销售额」。
- **滞销判定天数**：影响库存页的滞销标记和首页预警。
- 保存后立即重算，并存在本机浏览器；「恢复演示数据与默认设置」会清空本机设置。

## 8. 已知限制（本期不做）

- 不做多人账号与权限，单角色老板视图；
- 不做服务器部署，数据在本机浏览器内；
- 不直连淘宝 / 小红书开放平台 API，只做后台导出文件导入；
- 不做个税申报与自动报税，工资只做应发口径和固定代扣；
- 发票只做台账与金额匹配，不做税额抵扣计算；
- 商品成本采用移动加权平均，不提供先进先出等其它成本法。

## 9. 文件与自测

```
电商财务集成管理系统.html      ← 交付物，双击打开
src/                           ← 开发源码（HTML/CSS/JS，可继续维护）
build/build.mjs                ← 把 src 内联成单文件 HTML
tests/                         ← 62 个自动化断言（核算 / 导入 / 数据自洽）
docs/data-schema.md            ← 数据模型与核算口径
```

重新构建与自测：

```bash
node build/build.mjs
node --test
```

测试覆盖：移动加权成本、跨月退款、阶梯提成、费用分摊尾差、对账差异、发票匹配、CSV / XLSX 解析与校验、演示数据自洽与汇总勾稽。

> 本系统为演示与内部管理用途，不构成审计、税务或投资建议。真实经营请以平台账单、银行流水和发票原件为准。
