# 发布与回滚（草案，生产发布需技术负责人审批）

本期只交付本地可运行版本，**未做任何生产部署**。以下为后续上线时的约定：

1. **发布前**：CI 全绿；`docs/验收清单.md` 逐项勾选；数据库备份（`pg_dump -Fc`）并验证可恢复。
2. **迁移**：`prisma migrate deploy` 只执行已评审的迁移文件；含删表/删列/改类型的破坏性迁移必须单独评审、先备份、人工执行。
3. **发布**：构建镜像（`infra/Dockerfile`）→ 预发环境用客户授权的测试账号验证 → 生产。
4. **回滚**：保留上一版镜像；无破坏性迁移时直接切回上一版镜像；有破坏性迁移时用发布前备份恢复（`pg_restore`）。
5. **密钥**：JWT_SECRET、模型 Key、钉钉凭证由客户管理员录入服务器密钥管理，不经过聊天、代码或日志。
