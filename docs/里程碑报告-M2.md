# 里程碑报告 M2：钉钉工作台真机联调（2026-11-04）

## 结果
钉钉工作台 H5 微应用在测试企业里跑通：钉钉内免登 → 财务生成并提交月度经营简报 → 老板在钉钉内审核 → 钉钉工作通知送达。
验收方式：hanson 在 Mac mini（测试机）+ 手机钉钉上实际操作，口头确认“都没问题了”（2026-11-04 11:13）。本报告作者未直接看到通知截图。

## 本阶段改动（均已推送 main）
- 免登：`GET /auth/dingtalk/config`、前端 `requestAuthCode`、`bind-identity` 绑定命令；CorpId 可由首页地址 `&corpId=$CORPID$` 自动获取
- 测试环境：`infra/tunnel.sh`（cloudflared，必须 `--protocol http2`，国内网络拦 QUIC）、`infra/set-dingtalk-app.sh`（防填错位检查）
- Mac 安装脚本修复：`set -e` 下 for 循环静默退出、半成品目录、无 Homebrew 提示、国内镜像兜底
- 种子数据修复：`.env` 空密码项导致演示账号无法登录
- 服务器部署脚本草案：`infra/server/`（未在真实服务器运行）

## 测试
- 自动化（本容器真实执行）：单元测试全过，API 25/25
