# 里程碑报告 M3：平台智能表 / 知识库接入工作台（2026-11-05）

## 结果
工作台新增「数据源」：把钉钉（本期）里的 AI 表格和知识库接进工作台，方向单向（平台 → 工作台）。
按 hanson 2026-11-05 的说明和确认实现（见 `docs/待确认事项.md` Q14–Q20）：

- **情况一（客户没用智能表）**：在客户新建的空 AI 表格里一键生成模板表（订单含明细、费用、平台账单），字段与系统一致，字段对应自动确认，员工填表后定时同步。
- **情况二（客户已在用智能表）**：粘贴链接 → 选数据表和业务表 → 规则 + AI 给出字段对应**草稿** → 财务核对确认 → 预览 → 同步。之后按保存的对应关系定时同步。
- **同步规则**：复用文件导入的校验；有错的行整单不写、其余照常；同一张表允许多个来源（Q17）；同一编号数据来源之间不一致时**不自动覆盖**，列为冲突由财务选；平台上删掉的行先标记“来源已删除”，财务确认后才删（Q15）。每次同步记同步记录、导入批次和审计。
- **知识库**：数据型（全文进检索）与查询型（只同步标题/目录，点开跳回原文）；改为查询型时立即清掉已存正文。老板和财务可检索。
- 顺带修复：文件导入把“同一订单号多行商品”误判为“主键重复”（模板说明和示例本来就允许多行），legacy 与前端两份同步修改并补测试。
