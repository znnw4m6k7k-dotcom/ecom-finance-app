# 客户需求（试点客户填写）

> 本期没有真实试点客户，以下为 Demo 合同（`input/demo/.delivery/contract.json`）中的需求摘要，正式试点前请客户逐项确认或修改。

- 客户 / 行业：电商（淘宝/天猫 + 小红书）品牌方，财务集成管理。
- 使用人：老板（看报表、审核）、财务（导入、起草）—— 待确认（见待确认事项 Q3）。
- 办公平台：钉钉（测试）；最终需支持钉钉、飞书、企业微信三版。
- 数据来源：平台后台导出的订单/账单/打款、快递面单、ERP/采购、工资表、费用、发票（CSV / xlsx）。
- 核心指标：净利润与净利率、店铺利润排名、现金流（已回款/待结算/账期占款）、成本结构、库存与周转。
- AI 环节：月度经营简报草稿（待确认 Q1）。
- 模型：客户公司自选国内模型（待确认 Q6）。
- 不做：直连平台 API、报税、个税、原生审批。
