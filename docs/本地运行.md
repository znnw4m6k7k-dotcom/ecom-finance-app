# 本地运行

## 环境
- Node.js 22（`.nvmrc`），npm 10
- PostgreSQL 16（本机安装，或 `docker compose -f infra/docker-compose.yml up -d db`）

## 步骤

```bash
npm ci
npm run build                       # 编译各包 + prisma generate
cp .env.example .env                # 至少填 JWT_SECRET（16 位以上随机串）和 DATABASE_URL
set -a && . ./.env && set +a
npm run db:migrate                  # prisma migrate deploy
npm run db:seed                     # 写入虚构演示公司 luye-demo + 第二租户 other-demo
npm run dev                         # 启动 API + 页面：http://localhost:3000
```

账号（企业代码 `luye-demo`）：`owner`（老板，可审核）/ `finance`（财务）/ `viewer`（只读）。
密码取 `.env` 中的 `SEED_*_PASSWORD`，未填时为开发默认值 `owner-dev-123` / `finance-dev-123` / `viewer-dev-123`（仅限本地）。
重置演示数据：`node apps/api/dist/seed.js --reset`。

一键脚本（需要 Docker）：`infra/dev-up.sh`。

## 走一遍闭环
1. 用 `finance` 登录 → 左侧「经营简报」→ 选 2026年10月 →「生成 AI 草稿」→ 可「修改」→「提交老板审核」。
2. 退出，用 `owner` 登录 →「经营简报」→「审核通过并通知」。
3. 页面「通知记录」显示 `mock（模拟）已发送`：说明走的是模拟连接器，**没有真的发到钉钉**。

## 切到真实模型 / 钉钉
- 模型：`.env` 设 `MODEL_PROVIDER=deepseek`（或 qwen/moonshot/zhipu/doubao）、`MODEL_NAME`、`MODEL_API_KEY`、单价，重启。
- 钉钉：见 `docs/连接器能力矩阵.md` 的联调步骤；设 `CONNECTOR_PROVIDER=dingtalk`。
- 密钥只放 `.env`（不提交）或服务器密钥管理，不要贴到聊天里。

## 测试

```bash
npm run test:unit    # 核算引擎（Demo 原有 43 项）、前端图表（19 项）、简报/权限/模型适配/连接器（35 项）
TEST_DATABASE_URL=postgresql://app:app_dev_only@localhost:5432/ecomfin_test npm run test:api   # API 集成 22 项（真实数据库）
BASE_URL=http://localhost:3000 npm run e2e -w apps/web   # 浏览器冒烟（需本机有 playwright）
```

离线单文件演示版仍可生成：`npm run build:offline -w apps/web`（双击打开，不需要服务器，不含简报功能）。
