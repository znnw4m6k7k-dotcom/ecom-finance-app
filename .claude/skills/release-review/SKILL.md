---
name: release-review
description: 里程碑结束或准备发布前的评审清单。用户说“验收”“准备上线”“出里程碑报告”时使用。
---

1. 真实执行：`npm run build`、`npm run typecheck`、`npm run test:unit`、`npm run test:api`，记录命令与结果（未执行的明确写未执行）。
2. 逐项过 `docs/验收清单.md`；重点：租户隔离、权限、审计、AI 输出校验与失败路径、通知幂等、密钥不进代码/日志。
3. 安全检查：`git grep` 搜索疑似密钥；确认 `.env` 未提交；依赖告警（`npm audit`）记录处理意见。
4. 输出里程碑报告（`docs/里程碑报告-*.md`）：修改文件、运行命令、测试结果、剩余风险、下一阶段任务、人工验收项。
5. 不执行生产部署、破坏性迁移、真实外部通知或费用支出；这些只给出步骤和回滚方案，等人工审批。
