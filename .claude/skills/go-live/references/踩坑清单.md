# 上线踩坑清单（来自电商财务项目实战，2026-11）

每条：现象 → 原因 → 怎么防。标 [自动] 的已由 `infra/preflight.sh` 检查。

## 本机 / 测试机
1. **没有 Homebrew、没有数据库**：安装脚本直接退出。→ 脚本先找已装的 brew/Postgres.app；都没有时给出 Postgres.app 指引，不自动装 Homebrew。[自动：Node、psql、数据库连通]
2. **终端读不到「下载」文件夹**（macOS 隐私权限）：`Operation not permitted`。→ 代码包放「文稿」或项目目录；或在系统设置 → 隐私与安全性 → 文件与文件夹 给终端授权。
3. **`set -e` 下 for 循环静默退出**：最后一项不匹配时 `[ -x … ] && …` 返回非零，脚本无提示退出。→ 循环里用 `if …; then …; fi`。
4. **安装中断留下半成品目录**：再次运行 `git clone` 失败。→ 检测到无 `.git` 的目录先改名备份再重来（不删除）。
5. **私有仓库克隆弹密码**：卡住不动。→ `GIT_TERMINAL_PROMPT=0`，失败就用本地代码包（git bundle）。
6. **国内网络 npm / Prisma 引擎下载慢或断**：→ 探测不通时切 npmmirror 和 `PRISMA_ENGINES_MIRROR`。
7. **种子密码为空**：`.env` 里 `SEED_*_PASSWORD=` 空值被当成空串，演示账号登录不了。→ 空值回退到默认值；正式环境禁止种子。[自动：生产模式下检查]

## 内网穿透
8. **cloudflared 连不上**：国内网络常拦 QUIC。→ 必须 `--protocol http2`。[自动：检查 tunnel.sh]
9. **拿到地址但访问报 Error 1033**：地址分配后隧道还没注册成功。→ 等日志出现 `Registered tunnel connection` 再报告地址。
10. **隧道地址每次重启都变**：平台首页地址失效。→ 只用于测试；正式用云服务器 + 固定域名。[自动：PUBLIC_BASE_URL 为 trycloudflare 时在 --prod 下报错]

## 办公平台
11. **钉钉 CorpId / Client ID / Secret 填错位**：免登失败。→ 录入脚本检查：Client ID 不含 `_`/`-` 且不超过 40 位、CorpId 不等于 Client ID、AgentId 纯数字；首页地址用 `$CORPID$` 占位符自动拿 CorpId。[自动]
12. **Secret 出现在聊天截图**：→ 视为泄露，立即在后台重置；以后只用不回显的录入脚本。
13. **免登后提示“未绑定”**：这是正常的第一步。→ 让员工把页面显示的 userid 给管理员，用 `bind-identity` 绑定；不读通讯录。
14. **工作通知需要公网 HTTPS 和 AgentId**；群机器人只要 Webhook + 加签，最快验证。→ 先机器人后工作通知。[自动：工作通知模式下检查 HTTPS 地址和 AgentId]
15. **企业微信可信域名/可信 IP**：域名要备案且与企业主体相关，新建应用不配可信 IP 调不了接口。→ 资料清单 W6/W7 提前要。
16. 平台菜单和权限名经常改版。→ 联调前核对当前官方文档，清单写“以后台当前显示为准”。

## 云服务器
17. **大陆服务器未备案**：80/443 被拦，证书申请失败。→ 备案提前一到几周提交；期间用隧道测试。
18. **数据库端口暴露公网**：→ compose 里数据库不映射端口；安全组只放 22（限 IP）/80/443。
19. **Docker 官方源拉不到**：→ 按云厂商文档换镜像源。
20. **Node 版本差异**：测试机跑的 Node 版本 CI 没覆盖。[自动：要求 Node ≥ 20，并提示与 .nvmrc 不一致]

## 密钥与安全
21. `.env` 被提交 / 权限过宽。[自动：检查 git 跟踪与 600 权限]
22. 仓库里混进疑似密钥。[自动：扫描常见密钥格式]
23. 正式环境仍用模拟模型或模拟连接器却对外说“已接通”。[自动：--prod 下标出 mock]
