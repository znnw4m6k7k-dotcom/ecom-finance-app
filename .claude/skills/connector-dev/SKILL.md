---
name: connector-dev
description: 新增或修改办公平台连接器（钉钉/飞书/企业微信）。实现某平台的登录、通知、事件或入口能力时使用。
---

1. 先读 `docs/连接器能力矩阵.md` 和 `packages/workspace-connectors/src/types.ts`，只实现客户已选定的平台和能力。
2. 核对该平台**当前**官方文档（接口地址、签名、权限名、限流）；文档地址写进代码注释。
3. 凭证只从环境变量读取，并补到 `.env.example`（只写变量名）；日志和错误信息不得包含凭证或平台返回的敏感字段。
4. 回调/事件：必须验签（按平台协议）、去重（事件 ID 幂等）、快速应答、异步处理。
5. 单元测试用假的 fetch 覆盖：成功、平台错误码、超时、缺凭证；同步更新 `CAPABILITY_MATRIX` 与能力矩阵文档（测试会比对）。
6. 状态只能写“已实现未联调”，直到用客户授权的真实应用跑通并留下证据；Mock 不得说成已接通。
